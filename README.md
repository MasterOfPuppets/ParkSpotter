# ParkSpotter

ParkSpotter is a modern Android application designed for travelers and motorhome enthusiasts who need to find reliable parking and overnight spots without compromising their privacy.

Unlike other applications, ParkSpotter downloads raw data from OpenStreetMap (OSM) and processes everything locally. Your preferences and vehicle profile never leave your device.

## Features (v0.1 Baseline)
- Map-Centric Interface: Explore your surroundings using an interactive map (OSM).
- Privacy First: No cloud synchronization by default.
- Legal and Safety: Built-in legal notice system to ensure responsible parking.

## Tech Stack
- Language: Kotlin
- UI: Jetpack Compose with Material 3
- Maps: osmdroid
- Data: OpenStreetMap via Overpass API
- Architecture: Modern Android Architecture (Components, KTX, Coroutines)

## Disclaimer
Users are solely responsible for ensuring they park and stay overnight legally. ParkSpotter provides data and suggestions, but local signs and regulations always take precedence.
